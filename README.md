# 자소설 자기소개서 자동화 프로젝트 기획문서

## 1. 프로젝트 개요

### 1.1 목적

- 자소설(jasoseol.com) 사이트에서 ChatGPT 웹 앱을 활용한 자기소개서 작성 프로세스 자동화
- 매일 당일 공고의 자기소개서를 자동으로 작성
- 퇴근 후 작성된 내용만 검토하면 되도록 시간 절약

### 1.2 배경

- 현재 수동으로 ChatGPT를 활용해 양질의 자기소개서를 작성 중
- ChatGPT Projects '테오의 하입지'에 내 정보(경력, 기술스택 등)가 이미 저장되어 있음
- 반복적인 작업(공고 확인 → GPT 프롬프트 → 답변 복사)의 자동화 필요

### 1.3 핵심 가치

- **검증된 방법론**: 이미 품질이 확인된 GPT 프로젝트 활용
- **시간 절약**: 매일 2~3시간 소요되는 작업을 자동화
- **품질 유지**: 기존 수동 작성 방식의 품질을 그대로 유지

### 2.2 기술 스택

| 구분          | 기술                            | 선택 이유                        |
| ------------- | ------------------------------- | -------------------------------- |
| **언어**      | Python 3.10+                    | 자동화 라이브러리 풍부           |
| **웹 자동화** | Playwright + playwright-stealth | 안정적, 봇 탐지 우회             |

## 3. 자동화 플로우

### 3.1 전체 프로세스

```
[시작]
  │
  ├─ 1. 브라우저 초기화
  │    ├─ 자소설용 탭
  │    └─ ChatGPT용 탭
  │
  ├─ 2. 로그인
  │    ├─ 자소설 로그인 (세션 유지)
  │    └─ ChatGPT 로그인 (세션 유지)
  │
  ├─ 3. 자소설 → 채용공고 목록 페이지 접근
  │    └─ 당일 공고 중 즐겨찾기 안 된 것만 필터링
  │
  ├─ 4. 공고별 처리 루프
  │    │
  │    ├─ 4-1. 자소설 → 공고 상세 페이지 진입
  │    │
  │    ├─ 4-2. "나와 관련된 모집부문" 파싱
  │    │    └─ 테이블 형태: 신입 | Front-end | 51명 작성 | 자기소개서 쓰기
  │    │
  │    ├─ 4-3. 키워드 매칭 체크
  │    │    ├─ 설정된 키워드가 직무명에 포함되어 있는지 확인
  │    │    └─ 없으면 → 다음 공고로 스킵
  │    │
  │    ├─ 4-4. 공고 정보 추출 및 저장
  │    │    ├─ 회사명
  │    │    ├─ 공고 제목
  │    │    └─ 지원 직무 내용
  │    │
  │    ├─ 4-5. ChatGPT → '테오의 하입지' 프로젝트 진입
  │    │
  │    ├─ 4-6. ChatGPT → 회사/직무 정보 주입
  │    │    ├─ Step 1: 회사 정보 프롬프트 전송
  │    │    ├─ Step 2: 자기소개서 작성 규칙 프롬프트 전송
  │    │    └─ GPT 응답 대기
  │    │
  │    ├─ 4-7. 자소설 → "자기소개서 쓰기" 버튼 클릭
  │    │    └─ 문항 작성 페이지로 이동
  │    │
  │    ├─ 4-8. 문항 파싱
  │    │    └─ 각 문항의 질문 텍스트, 글자 수 제한 추출
  │    │
  │    ├─ 4-9. 문항별 처리 루프
  │    │    ├─ ChatGPT → 문항 질문 전송
  │    │    ├─ ChatGPT → 응답 완료 대기 및 답변 추출
  │    │    ├─ 자소설 → 해당 문항 입력란에 답변 붙여넣기
  │    │    └─ 다음 문항 반복
  │    │
  │    ├─ 4-10. 자소설 → "저장하기" 버튼 클릭
  │    │
  │    ├─ 4-11. 작성 이력 기록 (output/written_jobs.json)
  │    │
  │    ├─ 4-12. 자소설 → 채용공고 목록으로 복귀
  │    │
  │    └─ 다음 공고로
  │
  ├─ 5. 당일 모든 공고 처리 완료
  │
  ├─ 6. 브라우저 종료 (자소설 + ChatGPT)
  │
[종료]

```

### 3.2 주요 단계 설명

### **Step 1: 공고 필터링**

- 당일 공고 중 즐겨찾기가 안 된 공고만 수집
- 공고 상세 페이지에서 "나와 관련된 모집부문" 테이블 파싱
- 직무명에 설정된 키워드가 포함되어 있는지 체크
- 키워드 없으면 스킵, 있으면 다음 단계 진행

### **Step 2: 회사 정보 주입**

- ChatGPT '테오의 하입지' 프로젝트 진입
- 2개의 프롬프트 전송:
  - **프롬프트 1**: 회사명, 공고명, 직무, 공고 내용
  - **프롬프트 2**: 자기소개서 작성 규칙 (STAR 기법, 글자 수 준수 등)

### **Step 3: 문항별 답변 생성**

- 자소설 자기소개서 페이지에서 문항 파싱
- 각 문항마다:
  - ChatGPT에 질문 전송
  - 답변 대기 및 추출
  - 자소설 입력란에 복붙
- 모든 문항 완료 후 저장

## 4. 데이터 설계

### 4.1 설정 파일 (config/settings.yaml)

```yaml
# 자소설 설정
jasoseol:
  email: ${JASOSEOL_EMAIL}
  password: ${JASOSEOL_PASSWORD}
  login_url: "https://jasoseol.com/login"
  jobs_url: "https://jasoseol.com/jobs"

# ChatGPT 설정
chatgpt:
  email: ${CHATGPT_EMAIL}
  password: ${CHATGPT_PASSWORD}
  url: "https://chat.openai.com/"
  project_name: "테오의 하입지"

# 타이밍 설정
timing:
  between_questions_min: 1
  between_questions_max: 2
  between_jobs_min: 5
  between_jobs_max: 10
  page_load_timeout: 30

# 브라우저 설정
browser:
  headless: false # 개발: false, 운영: true
  viewport:
    width: 1920
    height: 1080
```

### 4.2 프롬프트 템플릿 (config/prompts.yaml)

```yaml
# Step 1: 회사 정보 프롬프트
company_info: |
  지원할 회사와 직무 정보입니다:

  [회사명]: {company}
  [공고명]: {title}
  [지원 직무]: {position}

  [공고 내용]:
  {description}

  이 정보를 기억해주세요.

# Step 2: 자기소개서 작성 규칙
writing_rules: |
  이제부터 자기소개서 문항을 하나씩 전달하겠습니다.
  각 문항에 대해 다음 조건에 맞춰 답변해주세요:

  1. 내가 프로젝트에 저장한 나의 정보를 활용
  2. 방금 전달한 회사/직무 정보와 연결
  3. STAR 기법 활용 (상황-과제-행동-결과)
  4. 구체적인 경험과 성과 포함
  5. 글자 수 제한 준수

  답변만 작성하고, 추가 설명은 하지 마세요. 준비되면 "준비 완료"라고 답해주세요.

# Step 3: 문항별 질문
question: |
  [문항]: {question}
  [글자 수 제한]: {max_length}자 이내

  답변을 작성해주세요.
```

### 4.3 키워드 설정 (config/keywords.yaml)


## 6. 예외 처리

### 6.1 예외 상황 및 대응

| 예외                  | 원인                       | 대응                      |
| --------------------- | -------------------------- | ------------------------- |
| **로그인 실패**       | 잘못된 비밀번호, 계정 정지 | 3회 재시도 → 종료         |
| **공고 없음**         | 필터링 후 결과 없음        | 로그 기록 후 정상 종료    |
| **키워드 매칭 안됨**  | 관련 직무 없음             | 해당 공고 스킵            |
| **버튼 찾기 실패**    | DOM 구조 변경              | 해당 공고 스킵, 로그 기록 |
| **GPT 응답 타임아웃** | 네트워크 오류              | 60초 대기 후 재시도 (3회) |
| **저장 실패**         | 필수 항목 누락 등          | 재시도 (1회) → 스킵       |
